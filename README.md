# KIMA EIS V3 — حزمة الاختبار الآلي المصغّرة

هذه نسخة **مصغّرة عمدًا** (59 ملفًا فقط، وليس المشروع الكامل) — تحتوي فقط
على ما يحتاجه ملف الأتمتة `.github/workflows/browser-tests.yml` ليعمل:
`30_WEB_APP/` (الكود) و`00_CONTROL/tasks/` (حزم الاختبار فقط، بدون
تقارير المهام التاريخية).

## طريقة الرفع من الهاتف (الأسهل)
1. فكّ ضغط هذا الملف على الهاتف.
2. من متصفح كروم، افتح مستودعك على GitHub → **Add file → Upload files**.
3. من نافذة اختيار الملفات على الهاتف، اختر **"تحديد الكل"** داخل
   المجلد الذي فككت الضغط فيه (وليس ملفًا واحدًا في كل مرة) — أغلب
   متصفحات الملفات على أندرويد تسمح باختيار مجلد كامل دفعة واحدة عبر
   "Select all" بعد الدخول للمجلد.
4. إن لم يقبل GitHub رفع مجلدات فرعية متداخلة دفعة واحدة من متصفح
   الهاتف (قيود معروفة على بعض الأجهزة)، ارفع كل مجلد فرعي على حدة
   بنفس الطريقة: `.github/workflows/`، ثم `30_WEB_APP/`، ثم كل مجلد
   داخل `00_CONTROL/tasks/` (13 مجلدًا صغيرًا، كل واحد بضعة ملفات فقط).
5. تأكد أن المسارات النهائية على GitHub مطابقة تمامًا لما هو هنا —
   لا تغيّر أسماء المجلدات ولا تُسطّح البنية.

بعد اكتمال الرفع، اذهب إلى تبويب **Actions** — سيبدأ التشغيل تلقائيًا.

## ملاحظة مهمة
هذه الحزمة **لا تحتوي** على وثائق المشروع الكاملة (`01_PRODUCT` حتى
`21_ANDROID_STARTER`) ولا `DECISION_LOG.md`/`V3_GAP_REGISTER.txt` —
فقط ما يلزم لتشغيل الاختبارات. للحصول على المشروع كاملًا، استخدم
`KIMA_EIS_V3_ADR036_FINAL.zip` من رسالة سابقة عند توفر وسيلة رفع أسهل
(كمبيوتر، أو تطبيق Termux، أو GitHub Desktop).
